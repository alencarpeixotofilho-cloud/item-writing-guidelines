# Item review checklist

Use one copy per item. Mark ✔ (meets), ✖ (does not meet) or — (not applicable).
Any ✖ in the **Critical** block means the item cannot be approved as is.

## A. Critical

| # | Criterion | ✔ / ✖ |
|---|---|---|
| 1 | The key is correct and supported by current evidence | |
| 2 | Exactly one option is the best answer | |
| 3 | The content is important and aligned with the blueprint cell | |
| 4 | The item can be answered with the options covered | |

## B. Stem and lead-in

| # | Criterion | ✔ / ✖ |
|---|---|---|
| 5 | The stem presents a realistic scenario with the information needed | |
| 6 | The lead-in is a direct, positively phrased question | |
| 7 | Findings are given as data, not interpretations (unless intended) | |
| 8 | No window dressing, red herrings or answer revealed in the stem | |

## C. Options

| # | Criterion | ✔ / ✖ |
|---|---|---|
| 9 | Options are homogeneous in category, length and detail | |
| 10 | Distractors are plausible to examinees lacking the knowledge | |
| 11 | No "all/none of the above", no combined options | |
| 12 | No absolute or vague frequency terms | |
| 13 | No grammatical, length or word-repeat cues | |
| 14 | Options are in logical order | |

## D. Language and classification

| # | Criterion | ✔ / ✖ |
|---|---|---|
| 15 | Clear, concise, unambiguous language; standard terminology and units | |
| 16 | Correct domain, competency and cognitive-level tags | |
