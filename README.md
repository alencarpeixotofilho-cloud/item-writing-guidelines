# Item-Writing Guidelines & Review Checklist

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white) ![License: MIT](https://img.shields.io/badge/license-MIT-green?style=flat-square) ![Status](https://img.shields.io/badge/status-in%20development-orange?style=flat-square)

> Best practices for writing and reviewing multiple-choice items, with an actionable checklist.

## 📌 Overview

Brings together established item-writing recommendations (NBME and national assessment-agency guidance) into a practical guide and a review checklist. Includes commented examples of well- and poorly-constructed items (all fictitious) and an automated checker for common item-writing flaws.

## ✨ Features

- Guide to writing the vignette, lead-in and options
- Criterion-based review checklist
- Catalog of common flaws (cueing, absolute terms, negative lead-ins, …)
- Commented examples (fictitious items)
- Automated item-writing flaw checker

## 🗂️ Repository structure

```text
item-writing-guidelines/
├── guide/          # item-writing guide (Markdown)
├── checklist/      # review checklist
├── examples/       # commented fictitious items
├── src/            # automated flaw checker
├── LICENSE
└── README.md
```

## 🚀 Getting started

```bash
python -m src.check examples/sample_item.md
```

## 🔒 Data & privacy

This repository contains **no real data** about students, faculty or institutions.
Every example runs on **synthetic data** generated by the project itself
(`examples/generate_sample_data`), using fictitious identifiers (`Student 001`, `Item 001`, …).
All test items shown in the examples are invented for demonstration purposes.
